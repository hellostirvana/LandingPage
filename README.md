# Stirvana Landing Page

This repository contains the public landing page for [Stirvana](https://stirvana.food).

Stirvana is currently validating its first personally coordinated Founding Tables in South Florida: small shared-meal experiences built around food, culture, and real conversation.

The public MVP has two mobile-friendly intake paths:

- Guest qualification through “Join an Experience”
- Provider qualification through “Host an Experience” for restaurants, chefs, instructors, cultural hosts, and venue partners

Submissions remain human-reviewed. The site intentionally does not provide accounts, public listings, automated matching, or payments during the first 5–10 experience validation cycle.

## Local development

- `npm install`
- `npm run build:css`
- Serve the repository with any static file server.

## Tech stack

- Static HTML and CSS
- Tailwind CSS built locally into `tailwind.css`
- GitHub Pages hosting
